# Security and privacy

Photo Tidy is designed to process photos locally on the iPhone. It has no server, account system, analytics pipeline, or app-owned image upload path.

If you find a security or privacy issue, please avoid posting sensitive details in a public issue. Contact the repository owner through the private contact method available on their GitHub profile and include a reproducible description, affected version, and device/OS information.

Please do not include personal photos, Photos-library exports, provisioning profiles, signing certificates, or other private material in an issue or pull request.
